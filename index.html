How to use: Append .json to any path below, or use the trailing-slash form (served as index.json). All responses are static JSON — write operations (POST/PUT/DELETE) are not supported.

Endpoints

Method Path Description
GET/posts/index.jsonAll posts (100)
GET/posts/{id}.jsonSingle post by id (1–100)
GET/comments/index.jsonAll comments (500)
GET/comments/{id}.jsonSingle comment by id (1–500)
GET/albums/index.jsonAll albums (100)
GET/albums/{id}.jsonSingle album by id (1–100)
GET/photos/index.jsonAll photos (5000)
GET/photos/{id}.jsonSingle photo by id (1–5000)
GET/todos/index.jsonAll todos (200)
GET/todos/{id}.jsonSingle todo by id (1–200)
GET/users/index.jsonAll users (10)
GET/users/{id}.jsonSingle user by id (1–10)
